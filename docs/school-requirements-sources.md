# Published requirements for the class entering in 2026

Researched 2026-10-11 for the class that starts dental school in calendar year 2026 (Class of 2030 for four-year programs, Class of 2029 for Pacific's three-year program). Schools almost never publish a class-specific list, so each seeded set uses the most recent public document and is filed under that graduating class. Check each against the school's current manual before students rely on it. Only requirement names and numbers that a source states are included; nothing is estimated.

Already covered elsewhere: Detroit Mercy (Class of 2028), NYU, ATSU Arizona and Midwestern Arizona (Class of 2027).
